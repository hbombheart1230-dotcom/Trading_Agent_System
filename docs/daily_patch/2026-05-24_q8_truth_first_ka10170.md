# 2026-05-24 Q8 Truth First And ka10170 Priority

## 목적

Q8 전술 검증은 수익률, 주문 수, 리포트 수가 맞는 샘플만 대상으로 한다. MTS 실현손익 탭과 가까운 `ka10170` 당일매매일지를 매매별 최종 성과 truth의 우선 소스로 승격한다.

## 변경

- `KiwoomDayPnlReader.get_day_trade_diary()` 추가.
  - `ka10170` 응답의 종목별 매수평균가, 매수수량, 매도평균가, 매도수량, 손익금액, 수익률, 수수료/제세금을 정규화한다.
- `libs/reporting/kiwoom_day_trade_diary_truth.py` 추가.
  - `ka10170` 종목 row를 symbol/qty/sell price/buy price 기준으로 매칭한다.
  - 단일 종목 row는 authoritative truth로 쓴다.
- `attach_broker_day_pnl()` 우선순위 변경.
  - 1순위: `ka10170`
  - 2순위: `ka10077`
  - 3순위: `ka10085`
- Q8 평가에서 broker/report truth가 깨진 샘플은 invalid sample로 분리한다.
  - `broker_alignment_status != ok`
  - broker/local missing count 존재
  - account snapshot error 존재
- Daily/weekly Q8 markdown에 invalid sample 예시를 표시한다.
  - `trade_id/symbol:reason`
  - tactic ID mismatch 예시도 함께 표시한다.
